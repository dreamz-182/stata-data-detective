# 数据侦探 · Stata 闯关学习器

这是一个零依赖的静态网页原型，用模拟执行的方式帮助学习者从 Stata 入门逐步走向完整实证工作流。

## 运行

直接打开 `index.html` 即可使用。也可以在当前目录启动任意静态服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 已实现

- 21 个连续关卡，分为新手侦探、清洗工坊、回归实战和综合案件四章
- 覆盖导入、查看、筛选、生成变量、分类统计、描述统计、可视化、回归、稳健标准误、分类变量、交互项、预测值和完整 do-file
- 三栏数据侦探界面
- 章节化课程地图和逐关解锁
- 已解锁命令工具箱
- 模拟 Stata 终端和命令历史
- 支持多行命令，最后一关可提交三步分析工作流
- 分层提示、错误类型区分和通关弹窗
- 星级评价和 `localStorage` 进度保存
- 桌面端、平板端和移动端布局
